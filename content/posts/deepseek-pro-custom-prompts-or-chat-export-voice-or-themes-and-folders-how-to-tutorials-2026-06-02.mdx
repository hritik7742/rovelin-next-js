## How to Create Custom Prompts for Repeating Tasks

### 1. Identify Repetitive Tasks
Before building prompts, document frequent requests. Common patterns might include:
- Writing meeting summaries
- Drafting technical documentation
- Generating code snippets
- Translating text between languages

### 2. Build and Save Custom Prompts
Follow these steps to create reusable templates:
1. Open DeepSeek AI in your browser
2. Click the Chrome toolbar icon for DeepSeek Pro
3. Select **Custom Prompts > New Prompt**
4. Write your template (e.g., *"Summarize this technical document in under 300 words, highlighting key metrics"*)
5. Add tags for categorization (e.g., "Meetings", "Tech Docs")
6. Save and name it clearly ("Tech Summary Template")

### 3. Use Prompts for Consistent Output
When you need to run a task:
- Click the DeepSeek Pro icon ▶ choose your prompt ▶ click **Insert**
This replaces typing and ensures consistent results across projects.

*Example:* A developer creates a custom prompt for code debugging:
> *"Given this Python script, identify syntax errors and suggest three optimization strategies."*

This saves time versus re-typing instructions each session.

## Organizing Chats with Folders: A Step-by-Step Guide

DeepSeek Pro introduces a file system approach to chat management. Here's how to implement it:

### 1. Create Project-Specific Folders
1. Open DeepSeek Pro settings
2. Click **Folders > New Folder**
3. Name it after a project (e.g., "Q3 Marketing Campaign")
4. Drag chat threads into the folder

### 2. Nested Folder Structure
For complex workflows, create subfolders:
- Parent: "Client Projects"
  - Child: "ABC Corp"
    - Subfolder: "Product Launch"

This mirrors your computer's file system while keeping AI conversations accessible.

### 3. Quick Access Shortcuts
Assign keyboard shortcuts to frequently used folders:
1. Go to **Settings > Keyboard Shortcuts**
2. Assign `Ctrl+Alt+M` to jump to your "Marketing" folder
3. Use `Ctrl+Alt+D` for development-related folders

This reduces mouse clicks and keeps workflows fluid.

## Exporting and Archiving Chats: A Practical Workflow

When you need to preserve or share AI-generated content:

### Export Options Available:
| Format        | Best For                     | File Size      |
|---------------|------------------------------|----------------|
| `.txt`        | Simple text documentation     | 100-500 KB     |
| `.json`       | Developer use cases           | 500 KB - 2 MB  |
| `.pdf`        | Formal reports                | 1-3 MB         |
| `.html`       | Web publishing                | 3-5 MB         |

### Export Process:
1. Select the chat ▶ click **Export**
2. Choose format and save location
3. Optional: Add file naming conventions (e.g., `2026-06-02_meeting_summary.txt`)

*Tip:* Use the **Batch Export** feature in DeepSeek Pro to archive multiple discussions at once—ideal for weekly project reviews.

## Customizing Your Interface with Themes

A well-designed workspace prevents burnout and improves focus:

### 1. Choosing a Theme
1. Navigate to **Settings > Themes**
2. Select from:
   - Dark Code (for developers)
   - Solarized Light (standard workspace)
   - Oceanic Deep (low-light environments)
   - Custom (upload your CSS)

### 2. Advanced Theme Customization
For CSS-savvy users:
1. Click **Custom Theme > Edit**
2. Modify variables like:
   ```css
   --primary-color: #FF6B6B;
   --background-color: #2E2E2E;
   ```
3. Save and preview instantly

This feature is particularly useful for teams needing brand-specific UIs.

## FAQ: Common Questions About DeepSeek Pro

### Can I sync folders between devices?
Yes, by enabling the **Cloud Sync** option in settings and connecting Google Drive or Dropbox.

### What export formats work best for developers?
`.json` is ideal for programmatic consumption, while `.txt` works well for simple logging.

### How do I backup my custom prompts?
Use the **Export All Prompts** option to save a `.json` backup file.

### Does the voice input work offline?
No, it requires an active internet connection for speech-to-text processing.
